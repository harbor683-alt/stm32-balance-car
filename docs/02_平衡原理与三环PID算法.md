## 一、车为什么能站起来

两轮车的重心在轮轴上方，天生不稳定，像倒立摆。能站住的唯一办法是**让轮子始终往"倒的方向"追**：

- 车往前倾 → 轮子往前加速，把重心"接住"；
- 车往后倾 → 轮子往后加速。

所以核心问题是两件事：**① 准确知道车身现在倾斜了多少度（姿态）；② 根据角度精确控制轮子加减速（PID）**。角度算不准或 PID 参数不对，车就倒。

## 二、姿态解算（10ms 周期）

小车在 `TIM1` 1ms 中断里每 10ms 算一次姿态，`main.c` 中完整流程：

```
MPU6050 读原始数据 (AX,AY,AZ,GX,GY,GZ)
   │
   ├─ 加速度计算角度（重力方向与车体关系）
   │     AngleAcc = -atan2(AX, AZ) / π * 180          ← 用 X、Z 轴加速度分量反推倾角
   │     中心校准：AngleAcc_Cali = AngleAcc + AngleAcc_Offset
   │     一阶低通（去振动噪声）：
   │     AngleAcc_Filter = 0.8*AngleAcc_Filter + 0.2*AngleAcc_Cali
   │
   ├─ 陀螺仪算角度增量（角速度积分）
   │     GY_Cali = GY + GY_Offset                      ← 零点校准
   │     AngleDelta = GY_Cali/32768 * 2000 * 0.01      ← 满量程±2000dps换算，10ms积分
   │
   └─ 互补滤波（融合两种来源，抑制漂移）
         Alpha1 = |DifSpeed|/5.0 * 0.02 + 0.005        ← 差速越大越信任加速度计
         Alpha1 限幅 ≤ 0.02
         Angle = Alpha1*AngleAcc_Filter + (1-Alpha1)*Angle
```

为什么需要融合？**加速度计**算的角度稳定但振动噪声大；**陀螺仪**积分平滑但会随时间漂移。互补滤波用"加速度计拉回来、陀螺仪平滑过去"的加权组合，两全其美。`Alpha1` 随差速动态调整：转弯剧烈时（差速大）更信任加速度计，防止陀螺漂移把角度带偏。

**倒地保护**：`|Angle| > 50°` 时判定倾倒，自动 `RunFlag=0` 停车，防止电机一直顶着地面猛转。

## 三、位置式 PID 公式（PID.c 逐项对应）

代码里实现的是离散位置式 PID，每个控制周期算一次：

```
e(k)  = Target - Actual                    ← 本次误差
P 项  = Kp * e(k)                          ← 误差越大纠正越用力
I 项  = I(k-1) + Ki * e(k)                 ← 历史误差累加，消稳态误差
        （限幅在 [OutMin, OutMax]，防积分饱和）
D 项  = -Kd * (Actual - Actual1)           ← 对"实际值"微分（微分先行），
                                              目标跳变时不产生尖峰
Out   = P + I + D
        Out>0 时 Out += OutOffset          ← 死区补偿，克服电机静摩擦
        Out<0 时 Out -= OutOffset
        输出限幅 [OutMin, OutMax]          ← 保护电机与驱动
Actual1 = Actual                           ← 存档供下次微分
```

四项工程化改进，对应源码注释，调试时最常遇到：

| 改进 | 作用 | 参数 |
|---|---|---|
| 积分限幅 | 误差长期消不掉时积分不爆，恢复快、不超调 | `IOut` 钳在 `[OutMin, OutMax]` |
| 微分先行 | 对实际值微分而非对误差微分，遥控打杆、目标跳变不抖车 | `DOut = -Kd*(Actual-Actual1)` |
| 死区补偿 | PWM 很小电机不转（静摩擦），输出同向叠加小偏移越过死区 | `OutOffset`（仅角度环设 3） |
| 输出限幅 | 单环输出不越界，防带飞 | `OutMax / OutMin` |

## 四、三环串级结构

```
                      ┌─────────────── 速度环(50ms) ───────────────┐
   目标速度(遥控) ────►│ SpeedPID.Target   SpeedPID.Out = 角度目标  │──► 角度环(10ms)
                      └─────────────── 实际速度 AveSpeed ◄─────────┘    │
                                                                       ▼
                                              AnglePID.Target ──► 角度环PID
                                                                   Out → AvePWM
                    目标转向(遥控) ──► TurnPID(50ms) ──► 差分 DifPWM ──► 合成：
                                                               PWML = AvePWM + DifPWM
                                                               PWMR = AvePWM − DifPWM
                                                               限幅 ±100 → Motor_SetPWM
```

**为什么速度环输出是角度环的目标？** 这是串级控制的关键设计：让车"前进"不是直接给电机加大 PWM，而是**让车身向前倾斜一点**——倾斜带来的重力分量自然让车加速，速度达到目标后角度环再让车身回正。这样速度控制本质是"控制倾斜量"，响应自然、不冲过头。这就是为什么速度环每 50ms 才更新一次（车太快不稳，太慢不跟手），角度环每 10ms 紧追。

三个环的职责和参数（`main.c` 结构体初值）：

| 环 | 周期 | 输入 | 输出 | 参数 | 作用 |
|---|---|---|---|---|---|
| 角度环 AnglePID | 10ms | Angle（互补滤波后） | AvePWM（±100） | Kp=3, Ki=0.1, Kd=3, OutOffset=3 | 保持直立，核心环 |
| 速度环 SpeedPID | 50ms | AveSpeed（左右均速） | 角度环目标（±10） | Kp=2, Ki=0.05, Kd=0 | 控制前进/后退速度 |
| 转向环 TurnPID | 50ms | DifSpeed（左右差速） | 差分 PWM（±30） | Kp=2, Ki=1, Kd=0 | 控制转弯 |

注意 `AvePWM = -AnglePID.Out` 有个**负号**：角度环输出为正意味着"要往前纠正"，而实际电机方向定义相反，所以取反——这是调参时最容易踩的坑，方向反了车会越追越倒。

## 五、调参实战（按顺序来）

> 先让车"能立住"，再谈速度，最后谈转弯。每步只动一个参数，改完观察现象。

### 第一步：只调角度环（Kp → Kd → Ki）

让车悬空（轮子离地），或手扶着车，用 K1 启动后观察：

| 现象 | 原因 | 做法 |
|---|---|---|
| 启动后直接倒下、毫无挣扎 | PWM 方向反 / 角度符号反 | 先检查 `AvePWM` 负号与编码器方向 |
| 轻微来回抖动（嗡嗡声） | Kp 过大 | 逐步减小 Kp（3 → 2 → 1.5） |
| 扶正后软绵绵、一碰就倒 | Kp 过小 | 逐步增大 Kp |
| 来回摆动幅度越来越大 | Kd 不足或方向反 | 增大 Kd（3 → 4 → 5）；若更糟，检查 D 项符号 |
| 立住但缓慢朝一边倒 | 陀螺/加速度零点偏移 | 需要校准 GY_Offset 与 AngleAcc_Offset（见 05 篇） |
| 立住但有低频缓慢晃动 | Ki 偏大 | 减小 Ki（0.1 → 0.05） |

### 第二步：调速度环（先给 Kp，再补 Ki）

让车在地面跑，K2 前进：

| 现象 | 原因 | 做法 |
|---|---|---|
| 不走，或走两步就倒 | 速度环 Kp 太小 | 增大 Kp（2 → 3 → 4） |
| 前进时前后剧烈点头 | 速度环 Kp 太大 / Ki 太大 | 减小 Kp 或 Ki |
| 起步慢、停下后仍缓缓前滑 | Ki 不足 | 增大 Ki（0.05 → 0.1） |
| 停下时过冲回退 | Ki 过大 | 减小 Ki |

### 第三步：调转向环

原地转方向盘看差速：

| 现象 | 原因 | 做法 |
|---|---|---|
| 打杆不转弯 | 转向环 Kp 太小 / 方向反 | 增大 Kp；检查 DifPWM 符号 |
| 转弯时车身晃 | 转向环 Kp 过大 | 减小 Kp |
| 转向响应慢、松杆后不回正 | Ki 不足 | 增大 Ki（1 → 1.5） |

### 调参底线

- **一次只改一个参数**，改完记录现象，方便回退；
- 参数改动后按 K4 短按（驻停）再重新 K1 启动，让 PID_Init 清零积分；
- 所有参数运行时会存在 Flash 里，恢复出厂值：删掉 `Store_Init` 写入的 0xB5B5 钥匙（重烧程序）即可重置。
