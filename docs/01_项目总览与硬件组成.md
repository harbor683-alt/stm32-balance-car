## 一、项目是什么

一个 **STM32F103C8T6 双端开源平衡车**：

- **小车端**：两轮自平衡小车，MPU6050 测姿态 + 编码器测轮速，三环串级 PID 维持直立，TB6612FNG 驱动直流减速电机；
- **遥控器端**：双摇杆 + 12 键手柄，NRF24L01 2.4G 无线控制，OLED 显示信号强度和小车回传数据；
- **两种无线控制方式**：NRF24L01 手柄遥控（默认）、手机蓝牙（USART2 透传）遥控，另有本机按键直控。
- **安全兜底**：RF/蓝牙任一模式连续 500ms 收不到有效控制包，自动清零速度/转向目标并原地驻停。

## 二、双端对比速览

| 项目 | 小车控制板 V2.0 | 遥控器 V3.0 |
|---|---|---|
| 主控 | STM32F103C8T6（72MHz，Cortex-M3） | STM32F103C8T6 |
| 无线 | NRF24L01（软件 SPI） | NRF24L01P-R + AT2401C 功放 + SMA 天线 |
| 姿态/反馈 | MPU6050（软件 I2C）+ 双编码器 | OLED 显示摇杆值与回传数据 |
| 驱动 | TB6612FNG 双路电机驱动 | 无（只发指令） |
| 供电 | DCDC 5V + LDO 3.3V | TP4057 锂电充电 + XC6206 3.3V |
| 输入 | K1~K4 四键 + RF + 蓝牙 | 双摇杆 + K1~K10 + 2 个摇杆按键（共 12 键） |
| 接口 | ST-Link SWD、USART1 调试、Type-C（供电） | ST-Link SWD、USB Type-C（充电/烧录） |

## 三、小车端引脚总表（以代码为准）

> 原理图见 `03_说明书和原理图/平衡车控制板-V2.0.pdf`，引脚映射全部来自工程代码。

| 功能 | 引脚 | 说明 |
|---|---|---|
| OLED（SSD1306，0.96"） | PB8=SCL，PB9=SDA | 软件 I2C，地址见 OLED 驱动 |
| LED | PC13 | 低电平点亮，运行指示 |
| 按键 K1 / K2 / K3 / K4 | PB1 / PB0 / PA5 / PA4 | 上拉输入，按下为低电平 |
| 电机 PWM（TIM2，20kHz） | PA0=左轮，PA1=右轮 | 72MHz / 36 / 100 分频得 20kHz |
| 电机方向（TB6612） | PB12~PB15 | 见 Motor.c，AIN/BIN 组合控制正反转 |
| 编码器 TIM3（左轮） | PA6=TI1，PA7=TI2 | 编码器模式，速度换算见下 |
| 编码器 TIM4（右轮） | PB6=TI1，PB7=TI2 | 同上 |
| MPU6050（软件 I2C） | PB10=SCL，PB11=SDA | 量程 ±16g / ±2000dps |
| NRF24L01（软件 SPI） | CE=PA8，CSN=PA15，SCK=PB3，MOSI=PB5，MISO=PB4 | **占用 JTAG 引脚，初始化时关 JTAG 留 SWD** |
| 蓝牙（USART2） | PA2=TX，PA3=RX | 9600，8N1，文本帧协议 |
| 调试串口（USART1） | PA9=TX，PA10=RX | 9600，打印运行状态 |
| 定时器节拍 | TIM1 | 1ms 更新中断，全工程调度心跳 |
| 烧录调试 | SWDIO/SWCLK | ST-Link 下载（JTAG 已禁用） |

**速度换算**（main.c 中）：`Speed = Encoder_Get(n) / 408.0 / 0.05`，其中 408 是电机减速比对应每圈脉冲数，0.05 是 50ms 测量周期换算成秒。单位是"圈/秒"。

## 四、遥控器端引脚总表

| 功能 | 引脚 | 说明 |
|---|---|---|
| 摇杆 ADC1 | PA0=左摇杆横向(LH)，PA1=左纵向(LV)，PA2=右横向(RH)，PA3=右纵向(RV) | 12 位，0~4095，回中约 2048 |
| 按键 | K1~K10 阵列 + 2 个摇杆按键 | 上拉输入，键码 1~12 |
| NRF24L01（软件 SPI） | CE=PB11，CSN=PB12，SCK=PB13，MISO=PB14，MOSI=PB15 | **与小车端引脚不同，勿照搬** |
| OLED | 与小车端同型号 | 显示 Sig/LH/LV/RH/RV 或回传数据 |
| 充电 | TP4057 + USB Type-C | 锂电池充电管理 |

**摇杆归一化**（AD.c + main.c 的 DataProcess）：原始 0~4095 → 减中值 2048 → 死区 ±100 归零 → `×101/1949` 缩放到 **-100~100**。

## 五、关键外设参数汇总

| 外设 | 参数 |
|---|---|
| MPU6050 | 加速度 ±16g，陀螺仪 ±2000dps |
| PWM | 20kHz（TIM2：PSC=36-1，ARR=100-1，72MHz 分频） |
| 编码器 | 408 脉冲/圈（减速比折算），TIM3/TIM4 编码器模式 |
| NRF24L01 | 2.4GHz 频段，2402MHz 信道，2Mbps，0dBm，32 字节定长 |
| OLED | SSD1306，128×64，软件 I2C |
| 蓝牙 | USART2，9600 8N1 |
| 看门狗 | 遥控失联 500ms 触发驻停（软件实现） |
