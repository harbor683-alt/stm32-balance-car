> 每一阶段都设计成"有可验证的现象"，不做纸上谈兵。

## 一、六阶段学习路线

| 阶段 | 内容 | 对应代码 | 你能看到的现象 |
|---|---|---|---|
| 1. 外设基础 | GPIO 输出/输入、按键消抖、OLED 显示、定时器中断 | `LED.c / Key.c / OLED.c / Timer.c` | LED 亮灭、按键响应、OLED 出字、1ms 中断跑计数 |
| 2. 运动控制 | PWM 调速、编码器测速、ADC 采样 | `PWM.c / Encoder.c / AD.c` | 电机转速随占空比变化、OLED 显示圈/秒、摇杆值 0~4095 |
| 3. 通信 | USART1 调试串口、USART2 蓝牙透传、文本帧解析 | `Serial.c / BlueSerial.c` | 串口助手收发、手机蓝牙控制小车前/后 |
| 4. 姿态 | 软件 I2C、MPU6050、低通滤波、互补滤波 | `MyI2C.c / MPU6050.c / main.c` 10ms 段 | OLED 角度随手晃动平滑变化、静止不漂 |
| 5. 控制 | 位置式 PID、三环串级、调参 | `PID.c` + 三环实例 | 车从"立不住"到"能站住"到"能走能转" |
| 6. 综合 | NRF 无线协议、数据回传、失联保护、调试菜单 | `NRF24L01.c / DebugMode.c` | 手柄控车、遥控器显示回传数据、拔遥控器 500ms 后车自动驻停 |

**建议顺序**：1→2 可以先在遥控器端做（它只有显示/按键/摇杆，没有平衡压力），3→6 在小车端做。

## 二、十个动手练习

按难度递增，每个都对应本工程真实代码，做完算入门：

1. **改开机界面**：把 `main.c` 开机四行 OLED 文字改成你自己的名字和版本号，重新编译烧录。
2. **换速度档位**：把 `SpeedLevel` 默认值从 4 改成 6，蓝牙满杆速度明显变快——体会"参数存 Flash"的意义。
3. **改按键行为**：把 K2（前进）的目标速度从 `KEY_MOVE_SPEED=2.0` 改到 1.0 和 4.0，各跑一次，感受速度环目标的作用。
4. **加一个 LED 呼吸灯**：用 1ms 中断的计数分频，让 PC13 的 LED 做 1Hz 呼吸（注意小车运行时 LED 被 RunFlag 占用，可在停机时演示）。
5. **改蓝牙协议**：在 `main.c` 蓝牙分支加一个 `[key,4,up]` 指令，模拟 K4 短按（驻停），手机端就能遥控停车。
6. **调试串口回显**：把 PID 三个环的 Target/Actual/Out 通过 USART1 每 50ms 打印一行，用串口助手画出角度环跟踪曲线。
7. **滤波器对比实验**：把互补滤波 `Alpha1` 的限幅从 0.02 改成 0.2 和 0.005，观察 OLED 角度是更"跟手"还是更"平滑"，理解滤波参数含义。
8. **调出"倒不了"的临界**：把角度环 Kp 从 3 往上加，找到车开始高频抖动前的临界值，再回退 20%，体会 Kp 的边界。
9. **加失联后 LED 提示**：在 `RemoteTimeoutFlag` 处理处加一句 LED 快闪逻辑，让"遥控失联"肉眼可见。
10. **恢复出厂参数实验**：改乱参数后重烧程序，验证"钥匙 0xB5B5 被清 → 自动写默认参数"的恢复机制。

## 三、进阶改进方向（按兴趣选）

- **上位机调参**：用 USART1 + 串口协议做上位机，把三环 Kp/Ki/Kd 在线下发，替代"改代码重烧"——上位机界面可以自己做，也可以用现成虚拟示波器协议；
- **滤波升级**：把一阶互补滤波换成卡尔曼滤波或 Mahony 姿态解算，对比抗振性，顺带学状态估计；
- **转向模式**：当前转向环控制差速，可加"原地转圈"模式（目标差速固定、速度目标为 0），体验不同控制策略；
- **循迹/避障**：在现有框架上加灰度传感器或超声波，把传感器输出换算成转向目标，复用三环；
- **把调试菜单接上线**：按 04 篇第七节启用 `DebugMode()`，完成"板上校准"闭环（现固件唯一缺的一环）；
- **低功耗**：遥控器端加按键唤醒 + 深度睡眠，让手柄待机电流降下来；
- **日志与故障恢复**：用 Store.c 记录最近一次停车原因（超时/倒地/按键），下次开机 OLED 显示，方便排查。
