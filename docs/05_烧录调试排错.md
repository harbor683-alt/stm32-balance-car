# 05 · 烧录调试排错

[上一篇：代码导读](./04_代码导读.md) · [返回项目首页](../README.md) · [下一篇：学习路线与进阶练习](./06_学习路线与进阶练习.md)

> 面向读者：第一次烧录、或车跑起来不对劲、或烧录失败的人。
> 建议按顺序走：先烧录成功 → 再自测 → 最后排错。

## 一、准备工作

| 项目 | 要求 |
|---|---|
| 软件 | Keil MDK 5.43（或相近版本），安装 STM32F1 器件支持包 DFP **2.4.1**（与工程一致） |
| 编译器 | ArmClang 6.24（工程已配置，勿用 AC5 打开） |
| 下载器 | ST-Link V2（或兼容 SWD 下载器） |
| 驱动 | ST-Link USB 驱动 |
| 工程路径 | 小车端 `01_小车烧录程序/Project.uvprojx`；遥控器端 `02_遥控器烧录程序/Project.uvprojx` |
| 固件 | 小车 `平衡车_RF与蓝牙双遥控版.hex`；遥控器 `遥控器_控制平衡车_数据回传版.hex` |

## 二、ST-Link 接线与设置

**接线（SWD 4 线）**：

| ST-Link | 小车端 / 遥控器端 |
|---|---|
| SWDIO | SWDIO 引脚 |
| SWCLK | SWCLK 引脚 |
| GND | GND |
| 3.3V | 3.3V（板载供电时可不接） |

**特别注意**：小车端 NRF24L01 用了 PA15/PB3/PB4 三个 JTAG 引脚，初始化时执行了 `GPIO_Remap_SWJ_JTAGDisable` **关闭 JTAG、保留 SWD**。所以下载调试走 SWD 接口，不要指望 JTAG；如果换了其他下载器，注意只接 SWDIO/SWCLK。

Keil 里 `Options for Target → Debug → Settings` 选择 ST-Link，Port 选 SW，确认能读到芯片 ID 后再 Download。

## 三、烧录步骤

两块板子都烧，顺序不限（互不依赖），但建议**先遥控器后小车**，方便联调：

1. 打开遥控器工程 → 编译（0 Error）→ Download；
2. 打开小车工程 → 编译（0 Error）→ Download；
3. 各自上电，OLED 正常显示即烧录成功。

小车工程编译参考结果（实测）：`0 Error(s), 0 Warning(s)`，Code=25812、RO=5604、RW=192、ZI=4192（约 25.8KB Flash，F103C8 的 64KB 绰绰有余）。

## 四、上电自测流程

1. 小车放平，上电 → OLED 显示"江协科技 平衡车测试程序 V1.0"，**按 K4 继续**；
2. 首次烧录会提示"已重置参数，请注意执行校准"，按 K4 继续（校准入口当前固件不可达，见第 04 篇第七节）；
3. 遥控器上电 → OLED 显示 `Sig:xx`，摇杆值随操作变化；
4. 遥控器 K9 切换 Mode，Mode=1 时显示小车回传数据；
5. 小车 K1 启动（OLED 第 5 行 `Mode:KEY`），手扶车把正，松手看是否站立；
6. K4 长按切换 `Mode:RF` → 遥控器打杆控制；再长按切 `Mode:BT` → 手机蓝牙控制。

## 五、常见问题速查

| # | 现象 | 原因与处理 |
|---|---|---|
| 1 | 烧录报错 `No target connected` | ST-Link 没识别：检查 SWD 四线、供电、板子是否上电；Option 里 Port 选 SW |
| 2 | 编译报错缺器件/头文件 | 未装 DFP 2.4.1，或编译器不是 ArmClang 6.24 |
| 3 | 烧录成功但 OLED 不亮 | 检查 OLED I2C 接线（PB8/PB9）与供电；确认模块地址与驱动一致 |
| 4 | 上电显示"已重置参数" | 首次烧录正常现象；之后每次上电若仍提示，说明 Flash 没写进参数（重烧即可） |
| 5 | 车启动后直接倒、不挣扎 | PWM 方向反：检查 `AvePWM = -AnglePID.Out` 负号与 Motor 方向脚接线 |
| 6 | 车抖动（高频嗡嗡） | 角度环 Kp 过大，减小 Kp（3→2→1.5） |
| 7 | 车立住但缓慢朝一边倒 | 陀螺/加速度零点未校准；现固件校准不可达，见 04 篇第七节启用 DebugMode |
| 8 | 原地轻微抖动停不住 | 死区补偿 OutOffset 偏大或 Ki 偏大 |
| 9 | 遥控器打杆车没反应 | 小车没切到 RF 模式（K4 长按到 `Mode:RF`）；双端 NRF 配置不一致（地址/信道）；遥控器 Sig 值低 |
| 10 | 手机蓝牙连不上/控制无反应 | 检查蓝牙模块接线（PA2/PA3）与 9600 波特率；小车切到 `Mode:BT`；指令格式必须是 `[joystick,0,60,0,0]\n` |
| 11 | 蓝牙控制后车不停 | 检查指令发送间隔：应 50~100ms 一包，超过 500ms 看门狗会停车（这是保护，不是故障） |
| 12 | 遥控器 `Sig` 长期低于 5 | 信号差：检查天线、距离、电池电压；AT2401C 功放供电是否正常 |
| 13 | 回传数据（Mode=1）不刷新 | 小车端没收到 ID=0x01（确认遥控器 Mode=1）；或双端包长度/地址不一致 |
| 14 | 回传的 Angle/Spd 数值乱跳 | float 大小端不一致（应同为小端）；或接收缓冲越界 |
| 15 | 校准菜单进不去 | 已确认：DebugMode() 未接线，属正常现象，按 04 篇第七节自行启用 |

## 六、调参的现场排错法

改参数前先做两个"方向检查"，90% 的"车立不起来"是这两个问题：

1. **PWM 方向**：手扶车，让车往前倾，观察电机是否往前转（追倒方向）。反了就改 `AvePWM` 的负号或对调 Motor 方向脚。
2. **编码器方向**：用手往前推车，OLED 的 SpdL/SpdR 应变正。反了，Encoder 计数方向反，速度环会正反馈，一启动就冲。

> 两个方向都正确后，再按 02 篇第五节的顺序调 Kp→Kd→Ki，一次只改一个参数。
