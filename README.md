# stm32-balance-car
STM32 两轮自平衡小车，采用双端独立控制板设计：小车端负责平衡与运动控制，遥控器端提供四按键操作界面，两者通过 NRF24L01 2.4G 射频模块通信，并支持蓝牙遥控与数据回传。OLED 实时显示模式状态，K4 长按即可在 RF / 蓝牙模式间切换。项目包含完整的 Keil MDK 工程源码（ArmClang 6 编译通过）、可直接烧录的 HEX 固件、详细烧录说明以及小车控制板 V2.0、遥控器 V3.0 原理图，适合作为 STM32 入门、平衡车控制的参考学习项目。程序版权归江协科技所有，可以查看、使用和修改，但不得据为己有。
# STM32 平衡车 · RF + 蓝牙双遥控

基于 STM32 的两轮自平衡小车。小车端与遥控器端各有一块独立控制板，支持四按键、2.4G RF 遥控与蓝牙遥控，OLED 显示当前模式。

> 仓库内同时提供 **Keil 工程源码** 和 **可直接烧录的 HEX 文件**，双端烧录说明见 [烧录说明](./先看我_小车和遥控器烧录说明.md)。

## 功能特性

- 四按键控制（前进 / 后退 / 左转 / 右转）
- 2.4G RF 遥控：NRF24L01，双端地址 `11 22 33 44 55`，频道 `2`（2.402 GHz）
- 蓝牙遥控，支持数据回传
- OLED 显示，K4 长按循环切换模式（`Mode:RF` 等）
- 双端独立 STM32 控制板，互不混烧

## 快速烧录

双端必须分别烧录，不能把同一份 HEX 烧到两边：

1. 小车断电 → 连接 ST-Link → 打开 `01_小车烧录程序/Project.uvprojx` → Download
2. 拔下 ST-Link，轮子悬空
3. 遥控器断电 → 连接 ST-Link → 打开 `02_遥控器烧录程序/Project.uvprojx` → Download
4. 双端上电，小车长按 K4 切换至 `Mode:RF`，轮子悬空轻推摇杆测试

完整步骤与排错（连不上芯片、识别不到等）见 [烧录说明](./先看我_小车和遥控器烧录说明.md)。

## 编译环境

- Keil MDK 5 + ArmClang 6.24（小车端 `0 Error, 0 Warning`；遥控器端 `0 Error`）
- STM32 标准外设库 / CMSIS
